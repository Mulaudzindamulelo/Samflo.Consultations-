- 12-month trend analysis
- Budget alert system

### 💰 Transaction Management
- Record income and expenses
- Categorize transactions
- Tax category tracking
- Client linking
- Invoice references

### 📄 Invoice System
- Create professional invoices
- Track invoice status (Pending, Paid, Overdue)
- Link invoices to clients
- Invoice templates
- Payment tracking

### 👥 Client Management
- Complete client directory
- Contact information storage
- Tax number tracking
- Revenue per client analysis

### 🎯 Budget Control
- Set spending limits by category
- Customizable alert thresholds
- Real-time budget monitoring
- Visual progress tracking

### 🔄 Recurring Transactions
- Automatic transaction generation
- Daily, weekly, monthly, yearly options
- Perfect for salaries, rent, subscriptions
- Reduce manual data entry

### 🏦 Tax Management
- Tax breakdown by category
- Estimated tax liability calculations
- South African tax rates included
- Compliance tracking

### 📊 Balance Sheet
- Assets vs Liabilities view
- Equity calculations
- Professional financial statements
- Financial position overview

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn
- Modern web browser

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/samflo-consultations.git
cd samflo-consultations
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Production Build

```bash
npm run build
```

Builds the app for production to the `build` folder.

## 🌐 Live Deployment

### Vercel (Recommended)

3. Import the repository
4. Vercel automatically deploys on every push

### Netlify

1. Connect your GitHub repository
2. Build command: `npm run build`
3. Publish directory: `build`
4. Deploy!

### GitHub Pages


## 💾 Data Management

### Storage
- All data stored locally in browser's localStorage
- No external servers or accounts required
- Complete privacy and control
- No data sent to any third parties

### Backup
- Export data as CSV files regularly
- Monthly backup recommended
- CSV files can be opened in Excel/Google Sheets

### Backup Steps
1. Navigate to each tab (Transactions, Invoices, Clients)
2. Click "Export" button
3. Save CSV files to safe location

## 🐛 Troubleshooting

### Blank Page
- Check browser console for errors
- Clear cache and refresh
- Ensure all dependencies installed

- Check browser localStorage is enabled
- Verify localStorage quota not exceeded
- Try different browser

### Slow Performance
- Clear browser cache
- Close other tabs
- Check internet connection
